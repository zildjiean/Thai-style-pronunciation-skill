# สคริปต์เสียง TTS สำหรับวิดีโอข่าวไซเบอร์

ใช้เมื่อผู้ใช้ส่งลิงก์ข่าวไซเบอร์ (เช่น The Hacker News weekly recap) เพื่อทำวิดีโอที่ใช้เสียง TTS ภาษาไทย ผู้ใช้ใช้ ElevenLabs และ Paxa Labs เป้าหมายคือให้เครื่องอ่านออกเสียงได้ถูกต้อง สูงต่ำตามที่คนไทยพูดจริง โดยไม่ต้องแก้มือ

## ผลลัพธ์ที่ต้องส่ง (สองส่วน)
1. **สคริปต์ TTS** เป็นไฟล์ .txt ข้อความล้วน พร้อมวางลงเครื่อง TTS ได้ทันที (ในแชท claude.ai ส่งไฟล์ให้ผู้ใช้ ใน Claude Code เขียนไฟล์ลงโฟลเดอร์ทำงาน)
2. **ข้อความบนจอ** แยกต่างหาก เรียงตามช่วงของสคริปต์ ใช้สะกดอังกฤษต้นฉบับ (เช่น PHP2Shell, CVE-2026-110264, CVSS 10.0, เวอร์ชันที่ต้องอัปเดต) สำหรับทำกราฟิก/ไตเติ้ล เพราะเสียงควรเป็นคำอ่าน แต่บนจอควรเป็นชื่อจริง

## ขั้นตอน
1. ถ้าผู้ใช้ไม่บอกว่าจะใช้เครื่องไหน ให้เขียนแบบกลางที่ใช้ได้ทั้งสองเครื่อง (ไม่มีแท็ก หยุดด้วยการขึ้นบรรทัด) แล้วบอกในหนึ่งบรรทัดว่าใช้แบบกลาง
2. เปิดลิงก์ด้วยเครื่องมือดึงหน้าเว็บ (เช่น WebFetch) ดึงเนื้อหาทุกหัวข้อ
3. ถ้าผู้ใช้ไม่บอกความยาว ใช้ค่าเริ่มต้นวิดีโอราวสามถึงห้านาที คัดข่าวตามความสำคัญ: ถูกโจมตีจริง > คะแนนวิกฤต/ไม่ต้องล็อกอิน > กระทบซอฟต์แวร์ที่ใช้กันกว้าง > เรื่องเอไอ/เทรนด์ > ข่าวจับกุม
4. เขียนด้วยคำของตัวเอง (paraphrase) ห้ามแปลยกย่อหน้าหรือคัดคำพูดยาวจากต้นฉบับ
5. โครงสร้างสคริปต์: เปิดด้วยประโยคดึงความสนใจหนึ่งถึงสองประโยค → บอกว่าเป็นข่าวสัปดาห์ไหน → ภัยคุกคามแห่งสัปดาห์ → ข่าวเด่นทีละเรื่อง → รอบโลกไซเบอร์แบบสั้น → บทสรุปสิ่งที่ควรทำ → ประโยคปิดท้าย
6. ปรับตามเครื่อง TTS (หัวข้อถัดไป)
7. ตรวจทานก่อนส่ง: รันคำสั่งสแกนไฟล์สคริปต์หา [A-Za-z0-9#*_()\[\]/ฯ] ต้องไม่เจอ ยกเว้นแท็ก break ที่ตั้งใจใส่สำหรับ ElevenLabs รุ่นที่รองรับ
8. ท้ายคำตอบ: ลิงก์ต้นฉบับสำหรับคำอธิบายวิดีโอ และรายการคำใหม่ที่ไม่อยู่ในอภิธานศัพท์ เผื่อทดสอบเสียงก่อนเรนเดอร์

## ปรับตามเครื่อง TTS

### ElevenLabs
- รุ่น Eleven v3 และ v4 ไม่รองรับแท็ก <break> ให้หยุดด้วยการขึ้นบรรทัดและบรรทัดว่าง ถ้าต้องการหยุดแบบลังเล ใส่ ... ได้เป็นครั้งคราว (ผลไม่คงที่เท่าแท็ก)
- รุ่นก่อนหน้า (เช่น Multilingual v2, Flash v2.5) ใส่ <break time="1.0s" /> ระหว่างข่าวแต่ละเรื่องได้ สูงสุดสามวินาที แต่อย่าใส่ถี่ เพราะแท็กเยอะทำให้เสียงเร่งหรือมีเสียงแปลก
- ถ้าผู้ใช้ไม่บอกรุ่น ให้ถือว่าเป็น v3 ขึ้นไป (ไม่ใส่แท็ก)
- ถ้าผู้ใช้ขอ สร้างไฟล์ pronunciation dictionary (.pls แบบ alias) จากอภิธานศัพท์ ใช้ใน Studio ได้ ดิกชันนารีตรวจจากบนลงล่างและใช้รายการแรกที่ตรง จึงต้องเรียงคำยาวก่อนคำสั้น (PHP2Shell ก่อน PHP) แนะนำให้ผู้ใช้ทดสอบกับเสียงไทยก่อนใช้จริง

### Paxa Labs
- ใช้โมเดล Paxa Flash รุ่นล่าสุด (ตอนนี้คือ paxa-tts-flash-v2) ออกแบบมาสำหรับไทยปนอังกฤษ แต่ยังเขียนเป็นอักษรไทยทั้งหมด เพื่อให้เสียงอ่านคงที่และตรงกันทั้งสองเครื่อง
- ไม่ใส่แท็ก SSML หยุดด้วยการขึ้นบรรทัดและเว้นวรรค
- ใช้เสียงพูดไทย ไม่ใช้เสียงกลุ่มที่เน้นภาษาอังกฤษ
- แนะนำให้ขอ timestamp ระดับประโยคจาก API เพื่อทำซับไตเติ้ลและจับจังหวะตัดต่อ

### TokenMe (Paxa ผ่าน API แบบ OpenAI)
- `POST https://api.tokenme.limited/api/v1/audio/speech` โมเดล `paxa/paxa-tts-flash-v2` เสียง `espresso` ส่ง `input`, `voice`, `response_format` (mp3/wav) และ `speed` ได้ (1.2–1.25 ใกล้จังหวะคลิป Reels, 1.0 ช้า)
- คีย์อ่านจาก `$TOKENME_API_KEY` หรือไฟล์ `tokenme-tts-api-key.txt` ห้ามคัดลอกคีย์ลงโปรเจกต์หรือ git
- API ไม่คืน timestamp ให้สังเคราะห์ทีละวลีของซับ แล้วต่อกัน จะได้เวลาซับที่ตรงทุกวลี บางครั้งได้ไฟล์ถูกตัดสั้น ให้เช็กความยาวแล้วขอใหม่
- เวอร์ชันวิดีโอใช้ `script.json` ที่แยก `show` (ข้อความบนจอ สะกดมาตรฐาน) กับ `say` (คำอ่านที่ส่งให้ TTS) เช่น show "นีแอนเดอร์ทัล" แต่ say "นีแอนเดอทั่ล"

## กฎรูปแบบสคริปต์ TTS
- ข้อความล้วนเท่านั้น: ไม่มีหัวข้อมาร์กดาวน์ ไม่มีบุลเล็ต ไม่มีตาราง ไม่มีอิโมจิ ไม่มีเครื่องหมายดอกจัน
- หัวข้อเขียนเป็นประโยคพูด เช่น "มาดูข่าวเด่นกันครับ เรื่องแรก" แทนหัวข้อตัวหนา
- ประโยคสั้น หนึ่งประโยคหนึ่งใจความ หนึ่งบรรทัดต่อหนึ่งประโยค
- เว้นวรรคระหว่างวลีเพื่อหยุดสั้น เว้นบรรทัดว่างระหว่างข่าวแต่ละเรื่องเพื่อหยุดยาวและเป็นจุดตัดฉาก
- ภาษาพูดเล่าข่าว เป็นกันเองแต่สุภาพ ลงท้าย "ครับ" เฉพาะตอนทักทาย ตอนเปลี่ยนเรื่อง และตอนปิด
- หลีกเลี่ยงคำพ้องรูปที่อ่านได้หลายแบบ เช่น "เพลา" ถ้าเลี่ยงไม่ได้ให้เปลี่ยนคำ
- ไม้ยมกใช้ได้ เขียนติดคำ (หลายๆ) ห้ามใช้ ฯ ฯลฯ และอักษรย่อไทย เช่น พ.ศ. กทม.

## หลักการเขียนคำทับศัพท์แบบออกเสียงจริง
ใช้ phonetic transliteration ตามเสียงที่คนไทยพูดจริง ไม่ใช่หลักราชบัณฑิตยสถาน
- ใส่วรรณยุกต์ตามเสียงพูด: กูเกิ้ล (ไม่ใช่ กูเกิล), โทเค่น, แอปเปิ้ล, พร็อกซี่, รูบี้, ซิสโก้
- กล้าใส่วรรณยุกต์ตรีให้ชัด เมื่อคนไทยพูดเสียงสูง: ผู้ใช้ฟังเทียบแล้วเลือก ดริ๊ฟ (ไม่ใช่ ดริฟต์), ดี๊ปเฟ้ก (ไม่ใช่ ดีปเฟก), โอ อ๊อธ (ไม่ใช่ โอออธ), แซ๊ส (ไม่ใช่ ซาส), เซลล์ฟ๊อส
- ตัดตัวสะกดการันต์ท้ายที่ไม่ออกเสียง เพื่อให้เครื่องไม่อ่านเกิน: Exploit → เอ็กปลอย, Drift → ดริ๊ฟ, Salesloft → เซลล์ล็อฟ
- ชื่อที่ออกเสียงได้หลายแบบ ใช้แบบที่คนในวงการพูดจริง ไม่ใช่เสียงภาษาต้นทาง: Qilin → คีลิน (ไม่ใช่ ฉีหลิน แบบจีน), Marquis → มาร์คี
- ถ้าไม่แน่ใจคำไหน ให้เสนอคำอ่าน 2–3 แบบให้ผู้ใช้ฟังเทียบก่อนใช้จริง (ใน Claude Code มีเครื่องมือ `thai-tts/variants.mjs` สร้างหน้าให้ฟังและเลือก) คำที่ผู้ใช้เลือกแล้วให้เพิ่มลงอภิธานศัพท์
- ตัวย่อที่อ่านทีละตัว: CVE → ซีวีอี, RCE → อาร์ซีอี, API → เอพีไอ, VPN → วีพีเอ็น, WAF → ดับเบิลยูเอเอฟ, SMB → เอสเอ็มบี, TLS → ทีแอลเอส, CA → ซีเอ, CVSS → ซีวีเอสเอส, KEV → เคอีวี, OT → โอที, ICS → ไอซีเอส, PHP → พีเอชพี, npm → เอ็นพีเอ็ม, RAT → แรท, MSP → เอ็มเอสพี, CI/CD → ซีไอซีดี
- ตัวย่อที่อ่านเป็นคำ: CISA → ซิซ่า, SCADA → สกาด้า, OWASP → โอวอสป์
- ส่วนประกอบสัญลักษณ์: 2Shell → ทูเชว, .md → ด็อทเอ็มดี, .NET → ด็อทเน็ต, .js → เจเอส, Rapid7 → แรพิดเซเว่น, Log4Shell → หล็อกโฟร์เชว
- คำประสมใช้คำอ่านตามตารางเสมอ ให้สอดคล้องกันทั้งสคริปต์: PHP2Shell → พีเอชพีทูเชว, Node2Shell → โหนดทูเชว, Keylogger → คีย์หล็อกเกอร์, Build Server → บิ๊วเซิร์ฟเวอร์
- คำที่มีคำไทยที่คนทั่วไปเข้าใจง่ายกว่า ให้ใช้คำไทยหรือพูดคู่กันครั้งแรก เช่น "อาร์ซีอี หรือการรันโค้ดจากระยะไกล"
