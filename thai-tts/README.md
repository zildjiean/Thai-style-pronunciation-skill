# thai-tts — พจนานุกรมคำอ่านภาษาไทยสำหรับ TTS

ใช้ร่วมกันทุกวิดีโอใน `video-content/videos/` เพื่อให้เสียงพากย์อ่านคำอังกฤษ ตัวย่อ และตัวเลขแบบที่คนไทยพูดจริง

- `lexicon.json` — พจนานุกรม: `term` คือคำที่เขียนบนจอ, `say` คือคำอ่านภาษาไทยที่ส่งให้ TTS, `verified: true` แปลว่ามีคนฟังเสียงจริงแล้วและผ่าน
- `thai-say.mjs` — แปลงข้อความซับเป็นคำอ่าน และจัดการพจนานุกรม
- `samples/` — ไฟล์เสียงทดลองจากคำสั่ง `sample`

## แปลงตัวเลขให้อัตโนมัติ

| บนจอ | TTS อ่าน |
| --- | --- |
| 2 ตัว, 3 วัน | สองตัว, สามวัน |
| 9.2, 5.4 | เก้าจุดสอง, ห้าจุดสี่ |
| 8.4.27 (เวอร์ชัน) | แปดจุดสี่จุดยี่สิบเจ็ด |
| 80% | แปดสิบเปอร์เซ็นต์ |
| 1,000,000 | หนึ่งล้าน |
| 109618 (5 หลักขึ้นไป เช่นเลข CVE) | หนึ่งศูนย์เก้าหกหนึ่งแปด |

คำอังกฤษที่อยู่กลางประโยคจะอ่านต่อเนื่องไปกับคำไทยรอบข้าง (ทำงานด้วยพีเอชพี) ถ้าคำนั้นขึ้นต้นวลี จะเว้นจังหวะหลังคำ (คลาวด์แฟลร์ เจอ…) อยากให้หยุดตรงไหนเพิ่ม ให้เขียน `say` เองในวลีนั้น

## คำสั่ง

รันจากโฟลเดอร์ `thai-tts/`:

```bash
node thai-say.mjs "Cloudflare เจอ exploit 3 วัน"
```

```bash
node thai-say.mjs add Grafana กราฟาน่า
```

```bash
node thai-say.mjs sample Grafana
```

```bash
node thai-say.mjs verify Grafana
```

```bash
node thai-say.mjs list --unverified
```

```bash
node thai-say.mjs check ../videos/<ชื่อโปรเจกต์>/script.json
```

- คำสั่งแรกแสดงคำอ่าน และเตือนคำที่ยังไม่มีในพจนานุกรม
- `add` เพิ่มคำใหม่ หรือแก้คำอ่านของคำที่มีอยู่ (`--case` ถ้าตัวพิมพ์เล็ก/ใหญ่มีความหมายต่างกัน เช่น LINE กับ line)
- `sample` สร้างไฟล์เสียงด้วย TokenMe ไว้ที่ `samples/` ให้ฟังก่อน
- `verify` ใช้หลังฟังแล้วเสียงถูกต้อง
- `list --unverified` ดูคำที่ยังไม่มีใครฟัง
- `check` เทียบ `say` ในสคริปต์กับคำอ่านจากพจนานุกรม (`fill` จะเขียน `say` ให้วลีที่ยังไม่มี)

## ตรวจเสียงทีละหลายคำ

```bash
node thai-say.mjs sample --unverified
```

สร้างเสียงของทุกคำที่ยังไม่ verified แล้วเขียน `review.html` (ฝังเสียงไว้ในไฟล์ เปิดด้วยเบราว์เซอร์ได้เลย) ในหน้านั้นติ๊ก "ถูก" หรือพิมพ์คำอ่านที่ถูก แล้วกด "คัดลอกคำสั่ง" มารันในโฟลเดอร์นี้ หลังแก้คำแล้ว สร้างหน้าใหม่ด้วย `node thai-say.mjs review`

## ใช้กับวิดีโอใหม่

ใน `script.json` เขียนแค่ `show` (ข้อความซับ) ก็พอ `scripts/tokenme-tts.mjs` จะสร้างคำอ่านจากพจนานุกรมให้ และเตือนคำที่ยังไม่รู้จักก่อนเรียก API ถ้าวลีไหนอยากคุมเอง (เรียงคำใหม่ เติมจังหวะหยุด ไม้ยมก ๆ) ให้ใส่ `say` เอง ค่าที่ใส่เองจะถูกใช้เสมอ
